ANDOS Referral — CORE icon set (61 icons · 4-tab app)

Ye poora set hai jo 4-tab app me use hota hai — Chat · Referrals · Wallet · Profile. White background, taaki har icon saaf dikhe.

Kaise feedback dein: jo icon pasand na aaye uska naam likh dein (ya naya SVG bhej dein) — baaki sab main update kar dunga. Har icon 2 tarah ka hota hai: bada aur chhote size (22/18/14 px) — chhote size me bhi saaf dikhna chahiye. Settings alag tab nahi hain — wo Profile ke andar hain.
